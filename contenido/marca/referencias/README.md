Son los archivos del proyecto de ChatGPT «mmorera · piezas» (`../chatgpt-proyecto.md`). Si se usa ChatGPT fuera de ese proyecto, se **adjuntan en cada conversación** (arte y diapositivas enteras) para que copie el clima, la materia y la tipografía, no el texto. `chatgpt-prompts.ts` lista lo que haya acá.
