## 3. Hallazgos críticos y advertencias técnicas

1. **Enrutamiento de Truckers Choice:**
   - La ruta `/es/contacto` o `/contacto` da **HTTP 404**. La única ruta válida bilingüe es `/es/contact` y `/en/contact`.
2. **Mr. Studio Tattoo tiene flujo interactivo completo:**
   - La URL directa `/booking` resuelve el hallazgo de la sesión 3 (donde el caso solo tenía enlace externo genérico). Permite interactuar con el selector anatómico real sin salir del navegador.
3. **Sección Servicios en el Home:**
   - Mide 3.282 px (45,6% del home). Es el área prioritaria para aligerar en la siguiente pasada, derivando el detalle técnico a las páginas de servicio de T26/T27.
4. **Doble patrón de botón flotante:**
   - En el home se muestra la cápsula «Hablemos» a `#contacto`; en `/casos-de-exito` y casos individuales se muestra el botón verde de WhatsApp. Esta discrepancia confunde al visitante y debe unificarse según lo planificado en T37.
